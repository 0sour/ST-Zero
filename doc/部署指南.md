# ST-Zero 部署指南

> 版本：v1.0
> 日期：2026-08-31

---

## 1. Docker 部署（推荐）

### 前置要求

- Docker ≥ 24
- Docker Compose ≥ 2.20

### 快速启动

```bash
# 克隆项目
git clone https://github.com/0sour/ST-Zero.git
cd ST-Zero

# 构建并启动
docker compose up -d --build

# 查看日志
docker compose logs -f
```

访问 **http://localhost:8000**

默认账号：`default-user` / `admin`（单用户模式内置管理员）

### 停止 / 卸载

```bash
docker compose down          # 停止（保留数据）
docker compose down -v       # 停止并删除数据卷
```

### 数据持久化

- 数据存储在命名卷 `st-zero-data`（挂载到容器 `/app/data`）
- 升级容器不丢数据：`docker compose pull && docker compose up -d`

### 环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `PORT` | 8000 | 服务端口 |
| `DATA_DIR` | /app/data | 数据目录 |
| `ENABLE_ACCOUNTS` | false | 多用户模式（true 开启登录） |
| `ALLOW_REGISTRATION` | false | 开放注册 |
| `DEFAULT_USER_ROLE` | user | 新用户默认角色 |
| `JWT_SECRET` | （必改） | JWT 签名密钥，生产环境务必修改 |

### 多用户模式

```yaml
environment:
  - ENABLE_ACCOUNTS=true
  - ALLOW_REGISTRATION=false   # 仅管理员创建用户
  - JWT_SECRET=your-random-secret
```

开启后访问需登录，首个用户自动成为管理员。

## 2. 本地开发

### 前置要求

- Node.js ≥ 20（推荐 22+，内置 node:sqlite）
- pnpm ≥ 9

### 启动

```bash
pnpm install
pnpm dev          # 开发模式（tsx watch）
pnpm start        # 生产模式（先 pnpm build）
```

访问 **http://localhost:8000**

### 测试

```bash
pnpm test         # 运行 68 个单元测试
```

### 测试数据

```bash
node scripts/seed.js    # 创建两组演示数据（需服务运行中）
```

## 3. 配置 AI 后端

登录后，点击顶栏 ⚙️ 设置 → 后端连接：

| 字段 | 说明 | 示例 |
|---|---|---|
| 后端类型 | OpenAI 兼容 / KoboldAI | openai |
| API 地址 | 后端服务地址 | `http://localhost:11434/v1`（Ollama） |
| 模型 | 模型 ID | qwen2.5 |
| API Key | 可选 | sk-... |

**Docker 内访问宿主机服务**：使用 `http://host.docker.internal:11434/v1`（macOS/Windows 自动支持，Linux 需 `--add-host=host.docker.internal:host-gateway`）

## 4. 目录结构

```
ST-Zero/
├── Dockerfile              # 多阶段构建
├── docker-compose.yml      # 一键部署
├── public/                 # 前端（静态文件）
│   ├── index.html          # 主界面
│   └── js/api.js           # API 客户端
├── src/server/             # 后端
│   ├── index.ts            # 应用入口
│   ├── start.ts            # 启动入口
│   ├── config.ts           # 环境配置
│   ├── db.ts               # SQLite（node:sqlite）
│   ├── auth/               # 认证（JWT/bcrypt/中间件）
│   ├── format/             # 格式兼容层（PNG/角色卡/世界书/聊天）
│   ├── engine/             # 计算引擎（世界书/正则/宏/prompt/预算）
│   ├── api/                # API 路由
│   └── backends/           # AI 后端适配器
├── tests/                  # 单元测试（68 个）
├── scripts/                # 工具脚本（seed/测试管线）
└── doc/                    # 开发文档
```
