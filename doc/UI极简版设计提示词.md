## 一、设计总纲

**极简冷峻 + 文学气质**：以"幽灵按钮 + 极简线条 + 无框表单 + 绝对灰阶层级 + 唯一一抹暗红"为核心语言，打造兼具 AI 角色扮演沉浸感与顶级工具体验的界面。对标 Notion / Linear 的冷峻克制，但注入"图书馆/剧本"的文艺气息——像在深夜图书馆阅读手稿，或像翻开一本轻小说。

## 二、硬性规范

1. **图标**：统一使用 Lucide 图标（线性风格，stroke-width 1.5），界面全程禁止使用表情符号
2. **设计标准**：极简工业设计水准，灰阶承担层级，色彩极度克制
3. **核心原则**：**"用明度差代替纯线条，用暗色和主题色替换纯白"**——深色 UI 中纯白线条会产生"光晕污染"，必须避免
4. **色彩纪律**：全屏只保留**唯一一抹暗红**（选中指示线、对话引线、关键交互 hover），其余全部黑白灰

## 三、视觉语言

### 3.1 色彩系统（亮暗双主题）

```
/* 暗色主题 */
--bg-void:      #1a1a1a      （深暖灰底，非纯黑）
--bg-deep:      #202020      （聊天区，稍亮）
--ink-1:        #e8e8e8      （主文字，近纯白）
--ink-2:        #9a9a9a      （次级文字）
--ink-3:        #6a6a6a      （弱化文字）
--gold:         #c0503a      （唯一主题色，暗红）
--gold-bright:  #d0604a      （高亮暗红）
--gold-dim:     rgba(192,80,58,0.1)  （暗红透明底）
--gold-line:    rgba(192,80,58,0.2)  （暗红细线）

/* 亮色主题 */
--bg-void:      #f7f3ec      （极浅暖米底，夕阳余晖感）
--bg-deep:      #fdfaf5      （聊天区，暖白）
--ink-1:        #333333      （主文字，深灰）
--ink-2:        #6b6b6b      （次级文字）
--ink-3:        #999999      （弱化文字）
--gold:         #b03a2a      （唯一主题色，樱桃红）
--gold-bright:  #c04a3a      （高亮樱桃红）
--gold-dim:     rgba(176,58,42,0.08)
--gold-line:    rgba(176,58,42,0.18)
```

**原则**：灰阶承担层级（背景灰 → 主文字深灰 → 辅助浅灰），**唯一一抹暗红**只用于：左侧选中指示线、对话引线、关键交互 hover。绝不大面积平铺。

### 3.2 排版系统

```
--font-display: 'Noto Serif SC', 'Songti SC', 'SimSun', serif   （角色名/大标题，衬线，文艺）
--font-body:    'Inter', 'PingFang SC', 'Microsoft YaHei', sans-serif  （正文，现代）
--font-mono:    'JetBrains Mono', 'Fira Code', monospace         （代码/数据，硬核）
```

**版式原则**：
- 角色名/大标题用衬线字体（宋体），字距 0.02-0.05em，营造"剧本/书籍"感
- 代码/数值用等宽字体，自带科技感与工业感
- 文字层级：角色名（衬线 14-15px 加粗）→ 正文（14-15px 深灰）→ 辅助（9-11px 浅灰）
- 行距 1.8，留白充足，像读轻小说而非发微信

### 3.3 背景系统

- 暗色：深暖灰 `#1A1A1A`（非纯黑，避免死黑）
- 亮色：极浅暖米 `#F7F3EC`（非纯白，隐约透出"夕阳余晖"文艺感）
- 模块区分：聊天区稍亮（`#202020`/`#FDFAF5`），侧栏/右侧面板用背景色差自然分割，分割线用深灰 `#2A2A2A`（非白线）
- 可选：极淡和纸噪点纹理（亮色 35% 透明度）

### 3.4 动效系统

| 动效 | 规格 | 用途 |
|---|---|---|
| 入场 | fade + translateY(12px)，400ms cubic-bezier(0.16,1,0.3,1) | 页面/面板入场 |
| 消息 | 逐字浮现（12ms/字） | AI 回复 |
| 开关 | 拨钮滑动 200ms 缓动 | 开关切换 |
| 选中 | 背景块 + 左线过渡 300ms | 角色/卡片选中 |
| 输入 | 下划线 hover/focus 变暗红 300ms | 输入框交互 |

**原则**：动效克制、物理感真实，所有动效 60fps。

### 3.5 组件风格（定稿）

| 组件 | 风格 |
|---|---|
| 按钮 | 幽灵按钮（透明底 + 1px 灰边 + 深灰字），hover 变暗红；主操作占满宽度 |
| 输入框 | 无框表单：透明底 + 下划线（hover/focus 变暗红），纯文字预览态 |
| 下拉 | 下划线 + 极细线条箭头，无底色框 |
| 卡片 | 无边框，悬停极浅暖灰底 + 左侧暗红细线 |
| 标签 | 极浅灰小字 + 字距 0.2em 全大写 |
| 消息气泡 | 无气泡，左侧 2px 暗红引线（引用块排版），用户靠右 |
| 开关 | 细轨道（2px）+ 空心圆环拨钮，开启黑底白点（浅色）/暗红底白点（深色） |
| 滑块 | 细轨道（2px）+ 空心圆环，已选中深灰/暗红 |
| 代码块 | 极浅底色 + 等宽字体 + 左侧暗红细线 |
| 弹窗 | 无边框，纯背景 + 柔和阴影 |
| 滚动条 | 极细（4px），灰 thumb |

### 3.6 布局

- **顶栏**：极简——左侧衬线 Logo（无红框），右侧图标按钮组（无边框，hover 变暗红）
- **左侧栏**：角色列表，选中态 = 2px 暗红指示线 + 极浅灰背景块（深色 `#2A2A2A`，浅色 `#F0EEEA`），名字保持深色/亮色
- **聊天区**：消息居中窄栏（max-width 720px），引线排版，大留白
- **右侧栏**：无框表单，两段式排版（Label 小字浅灰 + 内容大字深色）
- **底部**：输入框纯底色（深色 `#2A2A2A`，浅色 `#F5F4F2`）+ 柔和阴影，发送按钮未输入无底色、输入后变亮

## 四、交互细节（定稿）

1. **角色切换**：切换时聊天区淡出 → 新角色淡入（300ms）
2. **发送消息**：消息滑入 + AI 回复逐字浮现（12ms/字）
3. **swipe**：左右箭头 hover 变暗红，切换时消息水平滑动
4. **世界书条目**：hover 极浅暖灰底 + 左侧暗红细线
5. **选中态**：左侧 2px 暗红指示线 + 极浅灰背景块
6. **输入框**：下划线 hover/focus 变暗红，纯文字预览态
7. **发送按钮**：未输入无底色（纯灰图标），输入后变亮
8. **空状态**：衬线大标题 + 细线装饰

## 五、实现技术

- 纯 HTML/CSS/JS（与现有架构一致，无框架依赖）
- CSS 变量驱动亮暗双主题
- Lucide 图标内联 SVG sprite
- 动效：CSS transitions/keyframes + 少量 JS（逐字浮现、输入监听）
