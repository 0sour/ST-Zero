# ST-Zero UI 框架规划

> 版本：v0.2（已实现）
> 日期：2026-08-30
> 目标：定义 UI 信息架构、布局系统、导航模式、组件体系，作为三种风格示例稿的共同骨架
> 关联文档：功能规格调研.md（控件类型）、系统架构设计.md（技术栈）
> 实现状态：风格 C 已定稿（doc/ui-mockups/风格C-沉浸叙事.html），组件库已实现（doc/ui-mockups/组件库-风格C.html，30+ 自研组件），主界面已接入真实后端（public/index.html）

---

## 1. 设计原则

1. **聊天优先**：聊天是主界面，其他都是辅助面板（抽屉/弹窗），不喧宾夺主
2. **移动与桌面统一**：同一套组件，响应式布局（桌面三栏 / 移动单栏 + 抽屉）
3. **计算后移的体现**：UI 只做展示与交互，所有计算（token 计数、世界书激活预览）通过服务端 API 实时获取
4. **渐进式复杂度**：基础功能（聊天/角色卡）一目了然，高级功能（世界书/正则/预设）收纳在抽屉与弹窗中
5. **暗色优先**：角色扮演场景长时间阅读，暗色为主（风格 B 提供明亮备选）

## 2. 信息架构

```
ST-Zero
├── 登录页 /login
├── 主界面（聊天）
│   ├── 左侧栏：角色卡列表（搜索/排序/标签过滤/新建/导入）
│   ├── 中央：聊天区（消息流 + 输入栏）
│   └── 右侧栏（可切换）：角色编辑 / 世界书 / 正则 / 预设 / 设置
├── 管理面板 /admin（仅 admin 可见入口）
│   ├── 用户管理（列表/创建/启用禁用/角色/删除）
│   └── 站点设置
└── 弹窗层
    ├── 角色卡导入/导出
    ├── 聊天管理（切换/重命名/导入导出/删除）
    ├── 世界书条目编辑
    ├── 正则编辑
    ├── 预设管理
    ├── API 连接配置
    └── 确认对话框
```

### 2.1 导航模式

| 层级 | 模式 | 说明 |
|---|---|---|
| 一级 | 左侧栏（角色卡）+ 中央（聊天） | 常驻，桌面三栏布局 |
| 二级 | 右侧栏抽屉（角色编辑/世界书/正则/预设/设置） | 图标按钮切换，互斥打开 |
| 三级 | 弹窗（条目编辑/导入导出/确认） | 模态覆盖 |
| 管理 | `/admin` 独立路由 | 侧边栏条件渲染入口（仅 admin） |

```
│ 左侧栏    │ 聊天区                             │ 右侧栏（可折叠）│

│ │新建  │ │ │ 角色名 · 聊天标题    [⋯]       │ │ │ 角色编辑   │ │
│ │导入  │ │ ├───────────────────────────────┤ │ │ /世界书   │ │

│ ├──────┤ │ ├───────────────────────────────┤ │ └───────────┘ │
│ │角色卡 │ │ │ 输入栏：[附件][textarea][发送] │ │               │
│ │列表  │ │ └───────────────────────────────┘ │               │
│ │(网格) │ │                                   │               │
│ └──────┘ │                                   │               │
└──────────┴───────────────────────────────────┴───────────────┘
```

### 3.1 布局系统（移动）

```
┌──────────────────────────────┐
│ 顶栏：☰ | 角色名 | [⋯]        │
├──────────────────────────────┤
│ 聊天区（全宽）                │
│  消息气泡                    │
│  消息气泡                    │
│  消息气泡（swipe 箭头）       │
├──────────────────────────────┤
│ 输入栏：[textarea][发送]      │
└──────────────────────────────┘
  ☰ = 左侧栏抽屉（滑出）
  ⋯ = 右侧栏抽屉（滑出）+ 操作菜单
```

- 移动端：单栏，左侧栏/右侧栏均为滑出抽屉（overlay 模式）
- 底部导航（可选）：聊天 / 角色 / 世界书 / 设置 四个 tab
- 触控目标 ≥ 44px

## 6. 风格选定

**已选定：风格 C 沉浸叙事**（2026-08-30 确认）

- 深色暖调（深棕底 `#141210`）、金色强调色（`#d6b280`）、衬线字体（Georgia/宋体）、书卷气、沉浸感
- 背景系统：自定义背景图 + 预设主题色（深棕/暖褐/暗绿/暗红）+ 遮罩层（模糊/透明度/面板不透明度三滑块）
- 示例稿：`doc/ui-mockups/风格C-沉浸叙事.html`（桌面全屏视图）
