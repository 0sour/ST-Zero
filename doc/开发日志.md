# ST-Zero 开发日志

> 记录项目开发过程中的关键决策、实现内容与问题修复
> 起始日期：2026-08-30

---

## 2026-08-30

### 阶段一：调研与设计（已完成）

- 完成四大方向调研：SillyTavern 生态、主流 AI 对话项目、角色扮演平台、资源格式规范
- 产出 6 份开发文档：调研报告、PRD、系统架构设计、格式兼容层设计、核心算法规格、功能规格调研
- 关键结论：
  - 格式兼容是生命线（角色卡 PNG tEXt/世界书/正则/聊天 JSONL 必须 1:1 兼容）
  - 计算后移是核心架构决策（世界书扫描/正则/prompt 构建全部服务端）
  - 参考项目：ChungusHub（Svelte 5 + ST 格式兼容）、RisuAI、LibreChat

### 阶段二：UI 设计（已完成）

- 产出 3 种风格示例稿（暗色赛博/极简明亮/沉浸叙事），用户选定**风格 C 沉浸叙事**
- 构建组件库（30+ 自研组件，亮/暗双主题，无浏览器默认样式）
- 主界面第一稿 → 真实接入后端

### 阶段三：后端实现（已完成）

- 技术栈：Node.js 26 + Express + TypeScript + SQLite（node:sqlite 内置模块）
- 认证：JWT + bcrypt + 登录限流 + ver 版本号（密码变更后旧 token 失效）
- 格式兼容层：PNG tEXt chunk（chara/ccv3 + CRC-32）、角色卡 V1/V2/V3、世界书、聊天 JSONL
- 计算引擎：世界书扫描（关键词/正则键/选择性/递归/预算/8 位置）、正则引擎、宏替换、prompt 组装（Chat/Text 双模式）、token 预算
- API：auth/characters/chats/worlds/regex/presets/quick-replies/groups/settings/admin
- 后端适配器：OpenAI 兼容 + KoboldAI（SSE 流式）

### 阶段四：前端接入（已完成）

- 登录页 + JWT 管理 + API 客户端（纯 JS）
- 角色 CRUD/导入导出/收藏、聊天 SSE 流式、世界书条目编辑、正则编辑、预设持久化
- 快捷回复、群聊、聊天设置（场景覆盖/作者注/聊天级世界书）、persona
- 管理面板（用户 CRUD/角色/启用禁用）

### 阶段五：测试（已完成）

- vitest 4 + vite 8（rolldown 转换器），`@server` alias 解决模块解析
- 68 个测试：格式兼容层 24 + 计算引擎 37 + 认证 5 + token 预算 2
- 测试发现并修复 4 个真实 bug：
  1. 世界书预算裁剪逻辑错误（超预算条目被保留）
  2. 嵌套宏无法展开（{{random:{{char}},X}}）
  3. {{match}} 替换错误（$0 非 JS 完整匹配引用）
  4. 宏键大小写不匹配（{{wiBefore}} 查找失败）
