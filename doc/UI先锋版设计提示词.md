# ST-Zero 先锋版 UI 设计提示词

> 版本：v1.0
> 日期：2026-08-31
> 用途：作为前端设计/开发的可复用提示词，指导 ST-Zero 从"沉浸叙事"升级为"先锋艺术"级设计

---

## 一、设计总纲

将浏览器视作**交互式艺术画布**，跳出传统布局框架，打造突破常规 UI 认知、令人惊艳的数字交互体验。对标 Awwwards / FWA / CSS DesignAwards 每日最佳网站的设计品质。

## 二、硬性规范

1. **图标**：统一使用 Lucide 图标（线性风格，stroke-width 1.5-2），界面全程禁止使用表情符号
2. **设计标准**：对标 Awwwards 顶级网站水准，达到每日最佳网站同等设计品质
3. **创意自由度**：先锋视觉风格、实验性排版、流畅物理动效、极具冲击力的文字版式
4. **沉浸式体验**：融合代码与高级渲染逻辑，打造统一完整的精品页面

## 三、视觉语言

### 3.1 色彩系统（暗色为主）

```
--bg-void:      #0a0908      （纯黑底，深邃）
--bg-deep:      #12100e      （深棕黑）
--bg-panel:     rgba(18,16,14,0.72)  （玻璃面板）
--ink-1:        #f5efe6      （主文字，暖白）
--ink-2:        #a89f92      （次级文字）
--ink-3:        #6b6459      （弱化文字）
--gold:         #d4a95c      （主强调色，香槟金）
--gold-bright:  #f0c97a      （高亮金）
--ember:        #e05a3a      （余烬橙，危险/热感）
--jade:         #7fb69a      （玉绿，成功）
--violet:       #8b7fd4      （紫罗兰，信息）
```

**原则**：大面积纯黑留白，金色作为唯一高饱和强调色，色彩克制而精准。

### 3.2 排版系统

```
--font-display: 'Cormorant Garamond', 'Noto Serif SC', serif   （大标题，衬线，优雅）
--font-body:    'Inter', 'PingFang SC', sans-serif              （正文，现代）
--font-mono:    'JetBrains Mono', monospace                     （数据/代码）
```

**版式原则**：
- 大标题用衬线字体 + 超大字号（48-120px），字距宽松（letter-spacing 0.02-0.05em）
- 关键数字/数据用等宽字体，营造"仪器感"
- 文字层级：超大标题 → 章节标题（衬线 24px）→ 正文（14px）→ 辅助（11px 大写字母间距）
- 允许文字溢出、错位、竖排等实验性排版

### 3.3 背景系统

- 默认：纯黑 + 极淡的噪点纹理（防色带）
- 可选：用户上传背景图（暗化处理，overlay 黑色 60-75%）
- 动态元素：极慢速漂移的微光粒子（canvas 或 CSS 动画，opacity 0.03-0.06）
- 面板：玻璃拟态（backdrop-filter blur 24px + saturate 1.4），边框 1px rgba(212,169,92,0.12)

### 3.4 动效系统

| 动效 | 规格 | 用途 |
|---|---|---|
| 入场 | fade + translateY(24px) + blur(8px→0)，600ms cubic-bezier(0.16,1,0.3,1) | 页面/面板入场 |
| 悬停 | 元素上浮 4px + 金色光晕（box-shadow 0 0 24px rgba(212,169,92,0.15)） | 卡片/按钮 |
| 点击 | 波纹扩散（金色，600ms） | 按钮 |
| 消息 | 逐字浮现（每字 8ms 间隔，fade+rise） | AI 回复 |
| 背景 | 微光粒子缓慢漂移（60s 循环） | 全局氛围 |
| 数字 | 滚动计数（requestAnimationFrame 缓动） | token 数/统计 |
| 滚动 | 视差 + 元素渐显（IntersectionObserver） | 长页面 |

**原则**：动效必须"物理感"（缓动曲线真实），克制不喧宾夺主，所有动效 60fps。

### 3.5 组件风格

| 组件 | 风格 |
|---|---|
| 按钮 | 无圆角或 2px 小圆角；主按钮金色填充 + 黑色文字；次按钮透明 + 金色描边；hover 金色光晕 |
| 输入框 | 无圆角，底部 1px 金色线（focus 时扩展为 2px + 光晕），背景透明 |
| 下拉 | 触发器无圆角 + 底部线；菜单玻璃面板 + 金色选中态 |
| 卡片 | 玻璃面板 + 1px 金色边框（12% 透明度）+ hover 上浮 |
| 标签 | 无圆角，1px 金色描边，大写字母间距 |
| 消息气泡 | 无圆角，左侧 2px 金色竖线（角色），用户消息右侧 2px 灰线 |
| 弹窗 | 玻璃面板 + 金色边框 + 入场缩放模糊动画 |
| 滚动条 | 极细（4px），金色 thumb |

### 3.6 布局创新

- **顶栏**：极简——左侧 logo（衬线字标 + 金色圆点），右侧图标按钮组（无边框，hover 金色）
- **左侧栏**：玻璃面板，角色卡为"编号 + 名字"的极简列表（01 樱井千夏），hover 金色编号放大
- **聊天区**：消息居中窄栏（max-width 720px），两侧留白呼吸感
- **右侧栏**：玻璃面板，tab 为竖排大写字母（CHARACTER / WORLD / REGEX / PRESET）
- **底部**：输入栏悬浮于聊天区底部（玻璃 + 金色聚焦线）

## 四、交互细节

1. **角色切换**：切换时聊天区整体淡出 → 新角色淡入（300ms）
2. **发送消息**：按钮点击波纹 + 消息滑入 + AI 回复逐字浮现
3. **swipe**：左右箭头 hover 金色，切换时消息水平滑动过渡
4. **世界书条目**：hover 显示金色左侧线 + 内容渐显
5. **设置弹窗**：左侧竖排标签（大写字母），右侧内容，入场缩放模糊
6. **空状态**：大号衬线标题 + 金色细线装饰，而非图标

## 五、实现技术

- 纯 HTML/CSS/JS（与现有架构一致，无框架依赖）
- CSS 变量驱动主题（暗色为主，亮色为备选）
- Lucide 图标内联 SVG sprite
- 动效：CSS transitions/keyframes + 少量 JS（IntersectionObserver、requestAnimationFrame）
- 背景粒子：canvas 轻量实现（< 30 行）

## 六、验收标准

- [ ] 无表情符号，全部 Lucide 图标
- [ ] 暗色为主，金色唯一强调色
- [ ] 衬线大标题 + 等宽数据字体
- [ ] 玻璃拟态面板 + 噪点背景
- [ ] 所有交互有物理感动效
- [ ] 消息逐字浮现
- [ ] 角色卡编号列表风格
- [ ] 移动端可用（响应式）
